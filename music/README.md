# Background Music

Add royalty-free MP3 tracks here from YouTube Audio Library.

## Naming Convention
- `hype_1.mp3`         — intense, workout content
- `motivational_1.mp3` — myth busting, transformation
- `calm_1.mp3`         — science facts, sleep, diet

## Where to Download
1. Go to studio.youtube.com
2. Left sidebar → Audio Library
3. Filter: Genre → Electronic/Hip Hop, Mood → Energetic
4. Download and rename using convention above

## How it Works
Pipeline auto-selects music based on video topic:
- workout/gym/cardio → hype
- sleep/stress/yoga  → calm  
- protein/myths/fat  → motivational
